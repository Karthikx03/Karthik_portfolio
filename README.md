# Karthikeyan P — Cinematic Portfolio

Personal portfolio website for **Karthikeyan P** — AI · IoT & Embedded Systems Developer, Patent Holder, and Research Intern at IIT Guwahati, National Central University & Chang Gung University, Taiwan.

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Smooth Scroll:** Lenis

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
